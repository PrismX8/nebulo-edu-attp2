Stability

How the chat update works

Your message is shown as soon as you send it. A healthy live connection carries it first; the browser performs a quiet reconciliation later instead of requesting the full message history every second. If the connection drops, polling slows itself down and pauses most activity in background tabs. Each send has an ID, so a fallback or reconnect cannot create a duplicate post.
