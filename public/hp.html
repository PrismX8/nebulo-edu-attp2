Setup modes

The opening setup is a shortcut, not a permanent restriction. Use the mode that suits the session you want.

01

Chat-only

Opens Global Chat directly for a focused community experience.

02

Proxy + Games

Gives you the full Nebulo home: search, tabs, proxy options, games, and chat.

03

Games-only

Starts with the game library when that is all you need.

Use the back arrow or Change setup option where it appears to return to setup. It should keep the same complete set of available choices.

Home, search, and Quick Access

The Nebulo home is the quickest route to common destinations. Quick Access buttons open trusted shortcuts, while the search box uses the search engine chosen in Settings.

→

Open a shortcut

Select any Quick Access button. A new Nebulo tab opens when the destination uses the in-site browser.

→

Change the search engine

Open Settings, select a search engine, then return to Home. The change applies to future searches.

Browser tabs and proxy modes

Use the tab strip to switch, close, or revisit pages. The proxy choice in Settings controls which supported browsing engine a new proxy tab uses.

A

Start a new page

Enter a search or address from Home, then use the tab bar to keep more than one page open.

B

If a page needs a refresh

Reload the tab once. If it still fails, try another available proxy mode from Settings and reopen the page.

Games

Browse the organized game library, launch a title, and use the game page controls to return to the library or change setup when needed.

A game’s loading behavior comes from the game host. If one title does not launch, return to the library and try it again later rather than opening multiple copies.

Global Chat and message status

Messages show up immediately, then settle into their saved state. The text box stays available for the next message; small sends are held in a short, ordered outbox so a slow network does not freeze the composer.

●

Sending

The message is visible locally while it is being delivered. A healthy live connection is used first.

✓

Sent

The canonical message has been accepted and shared with connected people in the room.

!

Failed

Use Retry on that message after checking your connection. Nebulo keeps the same message ID for that retry so it cannot post twice.

Chat remains moderated and can enforce room permissions and slowmode. A failed or blocked message is not automatically retried repeatedly.

Achievements and cosmetics

The achievement deck tracks activity on this browser and device. Unlocks can include custom cursors, accent colors, and a quiet stars effect.

01

Earn normally

Visit areas of Nebulo, use Quick Access, customize settings, and explore the site to progress.

02

Equip from the deck

Choose an unlocked cosmetic. It applies right away and remains after refresh on this device.

Achievement progress and cosmetics are local browser data, not an account-wide inventory. Clearing site storage can remove them.

Settings, ad blocker, and privacy controls

Settings contains the practical controls for how Nebulo behaves: theme, particles, proxy mode, search engine, ad blocker, cloaking, and panic key.

01

Appearance

Choose a theme, reduce particles, and equip local cosmetics for a calmer or more expressive workspace.

02

Ad blocker

Turn the site-wide blocker on or off in Settings. Some embedded sites can still behave differently because they control their own page content.

03

Cloaking and panic key

Configure these controls before you need them. Test the key once after changing it so you know the selection saved.

Common fixes

My page looks old or an update is missing

Close the affected Nebulo tab and reopen it. A normal reload is usually enough for the current page scripts to load.

A chat message says Failed

Check that the chat tab is still connected, then select Retry. Do not repeatedly resend the same text; Retry uses the original delivery ID.

Chat messages are not arriving

Reload Global Chat once. The live connection reconnects automatically; if it cannot, the chat falls back to slower checks without flooding the network.

A game or proxied page will not load

Reload once, then return to Home or the game list and reopen it. For proxy pages, try another available proxy selection in Settings.

My cosmetics disappeared

They are stored locally in this browser. Check that site data was not cleared, then revisit Achievements to equip an unlocked item again.
